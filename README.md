# MyGame

Визуальная новелла на Ren'Py 8.5.3 о преподавателе, который ищет свою судьбу.

## Запуск

1. Установи [Ren'Py 8.5.3](https://www.renpy.org/)
2. Открой проект через Ren'Py Launcher
3. Нажми **Launch Project**

## Управление

- **ЛКМ / Пробел** — продолжить диалог
- **F1** — экран статистики
- **Shift+D** — меню разработчика
- **Shift+R** — перезагрузка скриптов

## Структура

- `game/chapters/` — главы сюжета
- `game/screens/` — кастомные экраны (карта, статистика)
- `game/images/` — графика
- `game/audio/` — звук
